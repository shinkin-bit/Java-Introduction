# Java Learning

My practice code and exercises while learning Java, built in Intellij IDEA.

## About
I'm following Kaupenjoe's Java playlist on Youtube. This repo holds the follow-along code plus my own attempts at the given exercises.

## Topics Covered
- Syntax, Data Types, Input & Output
- Operators, Boolean Logic, Ternary Operators, Casting
- Strings & Loops

## Exercises
- **Calculator (v1):** Two numbers are selected through an input scanner before selecting an operator. The result is displayed and the process terminates. Uses switches.
- **Mining Exercise (v1):** A block is selected at random via random number generator. Selecting the correct tool from the given choices will determine if a point is earned. Uses conditionals and switches.
